---------------- UPDATED THESIS RULES (POST-08 OCTOBER 2026 SUPERVISOR MEETING) ----------------
1. Primary Research Goal:
   Develop and evaluate a configurable Abaqus Python framework for adaptive mesh refinement in phase-field fracture simulations using native Abaqus error estimation and remeshing. The framework shall support automated pre-refinement and investigate sequential refinement during crack propagation, without requiring the crack trajectory to be prescribed in advance.

2. Three Methodological Approaches:
   - Method A (Two-pass pre-refinement): Current baseline. Coarse simulation -> MISESERI -> one remeshing operation -> fresh simulation from initial state. Zero state transfer required.
   - Method B (Multiple load partitions, one remeshing operation): Divide loading into 1, 2, or 4 Abaqus steps -> evaluate preliminary solution -> remesh once -> fresh final simulation. Allows studying loading schedules without sequential remeshing.
   - Method C (Sequential adaptive remeshing): Proposed extension. Load incrementally -> evaluate error -> remesh -> preserve required solution state -> continue loading. Strictly gated on verified state transfer and damage irreversibility (d_{n+1} >= d_n).

3. Governing Project Rule Revisions:
   - Remeshing methodology: Two-pass Pandey–Kumar reproduction remains the verified baseline; sequential remeshing is a separately investigated and gated extension.
   - Load-step selection: Do not hardcode two Abaqus steps. Load partitioning is configurable (1, 2, 4 partitions).
   - Solution increments: Control maximum displacement/time increment independently of Abaqus step count.
   - MISESERI evaluation: Explicitly record selected step/frame and compare candidate states. MISESERI is a recovered-stress discretization-error indicator on the companion linear-elastic continuum, not phase-field damage error.
   - Automatic remeshing: No manually prescribed crack path or refinement corridor in the general controller.
   - State transfer: Mandatory verification gate before claiming genuine continuation on a newly generated mesh.
   - Coarsening: Initially disabled; only investigate after damage irreversibility and mesh-to-mesh mapping have been verified.
   - Scientific validation: Require global force response, spatial crack measures, energy diagnostics, and solver performance.
   - Scope: Bulk material remains linear elastic with phase-field damage. Plasticity, contact, and alternative error indicators are future extensions.
   - Reproducibility: Preserve benchmark baselines, raw ODB evidence, configuration files, and scientific provenance.

4. Thesis Research Progression:
   1. Verified Pandey–Kumar reproduction (Mode-I baseline frozen).
   2. Mode-II validation (Job 1411267 closeout and diagnosis).
   3. Controlled load-partition study (1, 2, 4 steps on Mode-I benchmark).
   4. Sequential-remeshing feasibility and state-transfer verification.
   5. Automated comparative convergence and computational efficiency study (T_total = T_solver + T_remesh + T_transfer + T_pre/post).
   6. Curved-crack demonstrator (crack approaching a hole, subject to time and feasibility).
