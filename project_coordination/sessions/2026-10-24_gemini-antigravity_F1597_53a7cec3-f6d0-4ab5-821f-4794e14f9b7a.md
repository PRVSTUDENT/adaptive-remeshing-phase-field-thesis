## 3. Key Findings & Root-Cause Diagnosis

### The 2-Cycle Limit Oscillation
Inspection of the subproblem ledger revealed an exact periodic 2-cycle from iteration 7 to 25:
- **Odd Iterations (7, 9, 11, ..., 25)**: $|U|=58$, $|L|=4522$, $|A|=30$, 89 set changes, $\|R_d\|_{\infty, A} = 1.09 \times 10^{-5}$ kN mm, $RF_2 = 0.1141$ kN.
- **Even Iterations (8, 10, 12, ..., 24)**: $|U|=58$, $|L|=4467$, $|A|=85$, 89 set changes, $\|R_d\|_{\infty, A} = 1.48 \times 10^{-5}$ kN mm, $RF_2 = 0.1136$ kN.

### Causal Defect in Extraction vs Adapter Coupling
1. In Abaqus 2D planar meshes (`COORDINATES=2`), vector field output `U` only contains `(U1, U2)`. Field `U` does not output the scalar phase degree of freedom (DOF 3).
2. Consequently, [`extract_pdas_subproblem_odb.py`](file:///D:/Master%20thesis/Adaptive%20remeshing/models/pandey_kumar_mode1/97_pdas_iterative_continuation_pilot/extract_pdas_subproblem_odb.py) reconstructed nodal phase $d$ by averaging companion element `SDV1` at `ELEMENT_NODAL` positions.
3. Standard finite element shape-function extrapolation from Gauss points to corner nodes is an $L_2$ projection that introduces small polynomial smoothing errors of order $10^{-5}$.
4. In [`pdas_cluster_execution_adapter.py`](file:///D:/Master%20thesis/Adaptive%20remeshing/models/pandey_kumar_mode1/97_pdas_iterative_continuation_pilot/pdas_cluster_execution_adapter.py), `_extract_abaqus_results()` overwrote **all** nodes (including those in sets $L$ and $U$) with the smoothed Gauss-point values instead of enforcing the exact Dirichlet values ($d_k[L] \equiv d_{\text{ckpt}}[L]$ and $d_k[U] \equiv 1.000000$).
5. Because $d_{\text{extrapolated}}$ differed slightly from $d_{\text{ckpt}}$, the algebraic dual residual $R_d = F - K d_k$ was perturbed at boundary nodes. This caused 55 boundary nodes to flip between release ($L \to A$) and clamp ($A \to L$) in a perpetual 2-cycle.

## 4. Diagnostics, Errors, and Corrections

1. *Identification of Extrapolation Perturbation*:
   - *Error*: Live solver exhibited active set chatter, while offline mock solver converged in 13 iterations.
   - *Diagnosis*: Offline mock solver enforced exact Dirichlet nodal states $d[L] \equiv d_{\text{ckpt}}$ and $d[U] \equiv 1.0$, while the cluster adapter imported smoothed Gauss-point extrapolated states from the ODB.
   - *Correction Defined*: The adapter must preserve the exact Dirichlet partition invariant: for all nodes in $L_k$, $d_k \equiv d_{\text{ckpt}}$, and for all nodes in $U_k$, $d_k \equiv 1.0$. Only free nodes in $A_k$ should receive solver-computed phase values.
