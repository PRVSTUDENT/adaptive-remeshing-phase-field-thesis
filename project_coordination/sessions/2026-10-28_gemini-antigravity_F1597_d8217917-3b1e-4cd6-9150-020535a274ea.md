The history parsing routine was replaced with dynamic header-guided column resolution:
```python
def load_committed_history_and_d0(bounds_csv_path):
    h_committed_dict = {}
    with open(bounds_csv_path, "r") as f:
        header_line = f.readline().strip()
        header = [h.strip() for h in header_line.split(",")]
        h_idx = [i for i, h in enumerate(header) if h.startswith("H0_")]
        for line in f:
            line = line.strip()
            if not line:
                continue
            parts = [p.strip() for p in line.split(",")]
            eid = int(parts[0])
            h_vals = [float(parts[i]) for i in h_idx]
            h_committed_dict[eid] = h_vals
    return h_committed_dict
```
This guarantees that `h_idx` evaluates to `[5, 6, 7, 8]`, loading true strain energy history $\psi^+ \in [2.317 \times 10^{-8}, 8.386]\,\text{kN/mm}^2$.
