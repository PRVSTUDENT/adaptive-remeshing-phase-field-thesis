## 4. Fortran Memory Isolation & SVARS Layer Separation

   - Layer 1 (Phase UEL, elements $1 \dots N_{\text{PHYS}}$): Abaqus allocates and manages `SVARS(1..N_SVARS_U1)`. Elements use `SVARS(17)` for local history/energy within Layer 1.
   - Layer 2 (Mechanical UEL, elements $N_{\text{PHYS}}+1 \dots 2N_{\text{PHYS}}$): Abaqus allocates and manages a completely separate `SVARS` vector for each element in Layer 2. `SVARS(17)` in Layer 2 is stored in Layer 2's private state memory.
   - There is zero collision between Layer 1 `SVARS` and Layer 2 `SVARS`.

2. **Common Block Array Separation:**
   - In `f42_mixed_uel.for` (lines 76–79):

   - Layer 2 writes `SV_E_ELAS(PHYSIDX)` during mechanical quadrature integration.
   - Layer 3 reads both arrays concurrently without memory overlap.
