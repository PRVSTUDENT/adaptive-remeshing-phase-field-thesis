## 2. Real Abaqus 2023 Interface Validation & Missing RF3 Dual Residual Remedy

We executed cluster-side inspection on `/scratch9/pr21vyci/runs/mode1_package96_r4_c5_transfer/M1_C5_PACKAGE96_R4_TRANSFER.odb` using [`scripts/validation/inspect_remote_odb_fields.py`](file:///D:/Master%20thesis/Adaptive%20remeshing/scripts/validation/inspect_remote_odb_fields.py):

### Technical Finding: Absence of Phase Reaction Force (RF3)
- The Abaqus 2023 2D planar analysis output database contains field vectors:
  - $\mathbf{U}$: component labels `('U1', 'U2')`
  - $\mathbf{RF}$: component labels `('RF1', 'RF2')`
- Standard Abaqus `*Node Output` for 2D solid elements ignores degree-of-freedom 3 when recording reaction force $\mathbf{RF}$, even though degree of freedom 3 is active on user-defined elements (`*Element, type=U1`).
- As a consequence, an external Python driver cannot directly read dual phase multipliers $\boldsymbol{\lambda}_L$ or residuals $\mathbf{R}_d$ from ODB `RF` field outputs.

### Validated Remedy: Algebraic Dual Residual Evaluation
- The external PDAS controller extracts nodal phase field $d$ (from `SDV1`) and committed history $H$ (from `SDV2`) at each increment.
- The controller algebraically computes the exact discrete residual vector:
  $$\mathbf{R}_d = \mathbf{F}_{\text{phase}}(H) - \mathbf{K}_{\text{phase}}(H) \mathbf{d}$$
- On the lower-bound active set $\mathcal{L}$, the Lagrange multiplier is $\boldsymbol{\lambda}_L = -\mathbf{R}_d \ge 0$.
- On the upper-bound active set $\mathcal{U}$, the Lagrange multiplier is $\boldsymbol{\lambda}_U = \mathbf{R}_d \ge 0$.
- On the free set $\mathcal{A}$, the equilibrium residual must satisfy $\|\mathbf{R}_d\|_{\infty, \mathcal{A}} \le \tau_{\text{res}}$.
- This formulation preserves exact KKT complementarity evaluation while keeping the production UEL (`f42_mixed_uel.for`, hash `CE8D5EDCD2911DCB018BB15275271F874E7EA62B8FB48CF4A8297469A83ACDD6`) completely bitwise frozen.

   - **Mathematical Metric**:
     $$\epsilon_{\text{proj}} = \frac{|\Gamma(d_{\text{proj}}) - \Gamma(d_{\text{donor}})|}{\Gamma(d_{\text{donor}})} \times 100\%$$

   - **Mathematical Metric**:
     $$\epsilon_{\text{RF}} = \frac{|RF_{2, \text{receiver}} - RF_{2, \text{donor}}|}{RF_{2, \text{donor}}} \times 100\%$$
