## 4. Root-Cause Discovery: The State Extraction Contradiction

If the true finite element minimizer on these free nodes is $d \approx 0.96 - 0.998 > d_{\text{ckpt}}$, **why did Abaqus output $d_{\text{sol}} = 0.973202 < d_{\text{ckpt}} = 0.978257$ during Iteration 15?**

Direct examination of the cluster ODB output via guarded SSH inspection ([`remote_check_odb.py`](file:///D:/Master%20thesis/Adaptive%20remeshing/scripts/validation/remote_check_odb.py)) revealed the complete physical and technical mechanism:

1. **ODB Field Output Structure**:
   In standard 2D plane strain Abaqus ODB output, `frame.fieldOutputs['U']` contains **only two components: `('U1', 'U2')`**. The phase-field degree of freedom (DOF 3) from the user element is not stored in the standard displacement vector `U`.

2. **Extraction Fallback in `extract_pdas_subproblem_odb.py`**:
   Because `len(u_data) == 2 < 3`, the extraction script fell back to line 116:
   ```python
   d = nodal_d_from_sdv.get(nid, 0.0)
   ```
   where `nodal_d_from_sdv` was computed via:
   ```python
   sdv1_en = field_sdv1.getSubset(position=ELEMENT_NODAL)
   ```

3. **Companion Element State Definition in `f42_mixed_uel.for`**:
   In the frozen UEL, Layer 3 consists of CPE4 companion elements for visualization. In `f42_mixed_uel.for` lines 281-282:
   ```fortran
   D_AVG = 0.25D0 * (U(1) + U(2) + U(3) + U(4))
   SV_PHASE_TRIAL(PHYSIDX) = D_AVG
   ```
   and in UMAT lines 893:
   ```fortran
   STATEV(1) = SV_PHASE_TRIAL(PHYSIDX)
   ```
   `SDV1` is the element-averaged constant $D_{\text{avg}}$ across the 4 nodes of that element.

4. **Geometric Smearing at the Crack Boundary**:
   When `extract_pdas_subproblem_odb.py` averaged `SDV1` across the 4 elements sharing Node 2212, it averaged elements inside the crack wake ($d \approx 0.99+$) with adjacent elements outside the crack wake ($d \approx 0.94 - 0.96$):
   $$\text{Node 2212}: \frac{0.947960 + 0.967988 + 0.982632 + 0.994228}{4} = 0.973202$$
   This produced an artificial geometric downward smoothing of $d$ below $d_{\text{ckpt}}$ ($0.973202 < 0.978257$, $\Delta d = -0.00505$).

5. **The Driver's Contradiction**:
   - The PDAS driver inspected `d_extracted` and concluded that damage **healing** occurred ($\Delta d < 0$), triggering `clamp_L` ($A \to L$).
   - In the next iteration, locked at $d_{\text{ckpt}}$, the driver evaluated the algebraic residual $R_d = F - K d_{\text{ckpt}}$ using the **consistent nodal stiffness and force**. Because the true nodal minimizer is $d_{\text{exact\_qp}} = 0.998 > d_{\text{ckpt}}$, the algebraic residual was positive ($R_d > 10^{-6}$), triggering `release_L` ($L \to A$).
   - This established a perpetual limit cycle between algebraic nodal release ($L \to A$) and patch-averaged companion clamping ($A \to L$).
