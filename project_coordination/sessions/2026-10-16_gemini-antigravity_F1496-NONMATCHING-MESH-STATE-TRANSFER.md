## 3. Nonmatching State Transfer Operator & Crack Seam Segregation

1. **Topological Flank Segregation:**
   - A critical requirement in phase-field fracture on cracked domains is preserving the physical displacement jump and singular gradient across the crack slit.
   - The Mode-I geometry features a sharp slit along $y = 0.500\,\text{mm}$ for $0 \le x \le 0.500\,\text{mm}$. Nodes on the upper crack flank ($y = 0.5^+$) and lower crack flank ($y = 0.5^-$) are distinct physical entities sharing identical initial coordinates.
   - The state transfer engine (`scripts/state_transfer/mode1_state_transfer_engine.py`) partitions target nodes and Gauss points into 3 disjoint topological domains:
     - Upper flank domain ($\Omega^+$: $y \ge 0.500\,\text{mm}$, $x \le 0.500\,\text{mm}$): projects strictly from donor elements/nodes in $\Omega^+$.
     - Lower flank domain ($\Omega^-$: $y \le 0.500\,\text{mm}$, $x \le 0.500\,\text{mm}$): projects strictly from donor elements/nodes in $\Omega^-$.
     - Uncracked ligament domain ($\Omega_{\text{lig}}$: $x > 0.500\,\text{mm}$): projects from full donor domain.
   - This prevents unphysical cross-flank averaging, eliminating spurious displacement bridge forces and damage leakage across the slit.

2. **Interpolation & Mapping Formulations:**
   - **Nodal Displacements $(u_x, u_y)$:** Evaluated using linear/bilinear isoparametric shape functions within the host donor element enclosing each target node. Boundary nodes interpolate exactly between corresponding donor boundary sets.
   - **Integration-Point Damage ($d$) & History ($\mathcal{H}$):** Target quadrature points sample donor integration points using distance-weighted nearest-quadrature projection within the same topological flank. Peak values at the crack tip are exactly preserved without numerical dissipation.
   - **History Non-Negativity Enforced:** $\mathcal{H}_T(\mathbf{x}_q) = \max(\mathcal{H}_{\text{donor}},\, 1.0 \times 10^{-9}\,\text{kN/mm}^2) \ge 0$.
