## 2. Weak Form & Term-by-Term Energy Formulations

### A. Phase-Field Subproblem (Layer 1: JTYPE=1 Quad / JTYPE=3 Tri, Active DOF 3)
The discrete weak form governing the phase field is:
$$\int_{\Omega} \left[ \left(\frac{G_c}{l_0} + 2\mathcal{H}\right) d \delta d + G_c l_0 \nabla d \cdot \nabla \delta d \right] \mathrm{d}\Omega = \int_{\Omega} 2\mathcal{H} \delta d \,\mathrm{d}\Omega$$
The element crack surface dissipation energy is computed as:
$$E_{\mathrm{frac}}^{(e)} = \sum_{p=1}^{N_{\mathrm{int}}} w_p \det(\mathbf{J}_p) B \cdot G_c \left[ \frac{\bar{d}_e^2}{2 l_0} + \frac{l_0}{2} |\nabla d(\boldsymbol{\xi}_p)|^2 \right]$$
In the Fortran UEL, this is routed into:
- `ENERGY(7) = E_FRAC_ELEM` (standard Abaqus whole-element crack surface energy)
- `SVARS(17) = E_FRAC_ELEM` (phase element state variable array)
- `SV_E_FRAC(PHYSIDX) = E_FRAC_ELEM` (common block for companion UMAT transfer)

### B. Mechanical Subproblem (Layer 2: JTYPE=2 Quad / JTYPE=4 Tri, Active DOFs 1, 2)
The discrete equilibrium equation is:
$$\int_{\Omega} \boldsymbol{\sigma} : \boldsymbol{\varepsilon}(\delta\mathbf{u}) \,\mathrm{d}\Omega = \mathbf{F}_{\mathrm{ext}}$$
where the degraded stress tensor is:
$$\boldsymbol{\sigma} = \left[(1-\bar{d}_e)^2 + k_{\mathrm{res}}\right] \mathbb{C}_0 : \boldsymbol{\varepsilon}$$
The element elastic strain energy is computed as:
$$E_{\mathrm{elas}}^{(e)} = \sum_{p=1}^{N_{\mathrm{int}}} w_p \det(\mathbf{J}_p) B \cdot \left[ \frac{1}{2} \boldsymbol{\sigma}_p : \boldsymbol{\varepsilon}_p \right]$$
In the Fortran UEL, this is routed into:
- `ENERGY(2) = E_ELAS_ELEM` (standard Abaqus whole-element elastic strain energy)
- `SVARS(17) = E_ELAS_ELEM` (mechanical element state variable array)
- `SV_E_ELAS(PHYSIDX) = E_ELAS_ELEM` (common block for companion UMAT transfer)

### C. Non-Invasive Companion UMAT Bridge (Layer 3)
Whole-element scalar quantities are transferred non-invasively via `COMMON /CB_STATE_TRANS/` to the companion dummy material:
- `STATEV(17) = SV_E_FRAC(PHYSIDX)`: Element fracture dissipation energy $E_{\mathrm{frac}}^{(e)}$ [$\mathrm{kN\cdot mm} = \mathrm{J}$]
- `STATEV(18) = SV_E_ELAS(PHYSIDX)`: Element elastic strain energy $E_{\mathrm{elas}}^{(e)}$ [$\mathrm{kN\cdot mm} = \mathrm{J}$]
- `STATEV(19) = SV_PSI_F(PHYSIDX)`: Area-normalized fracture density $\bar{\psi}_f = E_{\mathrm{frac}}^{(e)} / A_e$
- `STATEV(20) = SV_PSI_E(PHYSIDX)`: Area-normalized elastic density $\bar{\psi}_e = E_{\mathrm{elas}}^{(e)} / A_e$
- Non-invasiveness invariant: Companion UMAT defines `DDSDDE(I,I) = 1.D-11`, `STRESS(I) = 0.D0`, `SSE = 0.D0`, `SPD = 0.D0`, and `SCD = 0.D0`, ensuring zero contribution to the global stiffness matrix and zero double-counting of energies.
