## 3. Mathematical Proofs of Under-Relaxation Viability

### Theorem 1: Pointwise Damage Irreversibility Under Convex Relaxation
Let $d_0(\mathbf{x}) \in [0, 1]$ be the transferred immutable lower bound. Let $d^{(k)}(\mathbf{x}) \ge d_0(\mathbf{x})$ be the damage field at iteration $k$. Let $\tilde{d}^{(k+1)}(\mathbf{x})$ be the solution of the phase-field subproblem, where the PDAS active-set algorithm enforces $\tilde{d}^{(k+1)}(\mathbf{x}) \ge d_0(\mathbf{x})$ pointwise.
For any relaxation parameter $\omega_d \in (0, 1]$, the updated damage field is:
$$d^{(k+1)}(\mathbf{x}) = (1 - \omega_d) d^{(k)}(\mathbf{x}) + \omega_d \tilde{d}^{(k+1)}(\mathbf{x})$$
Since $(1 - \omega_d) > 0$ and $\omega_d > 0$:
$$d^{(k+1)}(\mathbf{x}) \ge (1 - \omega_d) d_0(\mathbf{x}) + \omega_d d_0(\mathbf{x}) = d_0(\mathbf{x}) \quad \forall \mathbf{x} \in \Omega$$
$\blacksquare$

### Theorem 2: Preservation of Physical Fixed Point Set
Let $\mathcal{T}: d \mapsto \tilde{d}$ denote the coupled nonlinear mapping $\mathcal{T} = \mathcal{S}_d \circ \mathcal{H} \circ \mathcal{S}_u$.
The damped Picard operator is $\mathcal{T}_{\omega} = (1 - \omega) \mathcal{I} + \omega \mathcal{T}$.
A state $d^*$ is a fixed point of $\mathcal{T}_{\omega}$ if and only if $d^* = \mathcal{T}_{\omega}(d^*)$:
$$d^* = (1 - \omega) d^* + \omega \mathcal{T}(d^*) \iff \omega (d^* - \mathcal{T}(d^*)) = 0$$
Since $\omega > 0$, this is equivalent to $d^* = \mathcal{T}(d^*)$.
Thus, introducing under-relaxation alters only the transient trajectory, not the converged equilibrium state.
$\blacksquare$

### Theorem 3: Spectral Contraction of the Alternating Limit Cycle
In the neighborhood of the fixed point, linearizing the operator gives perturbation error $e^{(k+1)} = \mathbf{J} e^{(k)}$.
For the undamped alternating system, the measured limit cycle corresponds to an eigenvalue $\lambda = -K_\text{loop} = -1.0000$.
The damped iteration operator matrix is $\mathbf{J}_{\omega} = (1 - \omega) \mathbf{I} + \omega \mathbf{J}$.
Its eigenvalues satisfy:
$$\lambda_{\omega} = 1 - \omega + \omega \lambda = 1 - \omega (1 - \lambda)$$
Substituting $\lambda = -1.0000$:
$$\lambda_{\omega} = 1 - 2\omega$$
- For $\omega = 1.0$ (undamped): $\lambda_{\omega} = -1.0000$ (asymptotic limit cycle, $|\lambda| = 1$).
- For $\omega \in (0, 1)$: $|\lambda_{\omega}| < 1$ (strictly contractive).
- For $\omega = 0.5$ (optimal): $\lambda_{\omega} = 1 - 2(0.5) = 0.0000$ (superconvergent deadbeat response).
$\blacksquare$
