3.1 Coarse Pre-Analysis with Infinitesimal Companion Tangent:
-------------------------------------------------------------
The preliminary analysis executes on the 2,906-element mesh up to u_pre = 0.0050 mm
(alpha = 0.854) using an infinitesimal companion tangent (E_dummy = 1.0E-11 kN/mm^2)
to recover valid, non-zero von Mises stress discretization error indicators (MISESERI)
without perturbing phase-field fracture mechanics.

Run options:
  - 1-Step Partition: M1_PRE_INF_1S (500 increments, dt = 0.002)
  - 2-Step Partition: M1_PRE_INF_2S (Step 1: 250 incs, Step 2: 250 incs)
  - 4-Step Partition: M1_PRE_INF_4S (Step 1-4: 125 incs each)

Execution syntax:
abaqus job=M1_PRE_INF_1S user=f42_mixed_uel.for cpus=1 interactive

3.2 Native Abaqus CAE Adaptive Remeshing Orchestration:
-------------------------------------------------------
Execute native Abaqus CAE Python remeshing on the completed pre-analysis ODB:
abaqus cae noGUI=remesh_m1_native.py -- \
  --odb=M1_PRE_INF_1S.odb \
  --rule=RemeshRule-M1 \
  --error_target=1.0 \
  --output_mesh=ADAPTED_MESH_1S.inp

This generates exactly 14,677 base finite elements (14,646 nodes) with bitwise
identical topology across 1S, 2S, and 4S partitions.

3.3 Multi-Layer UEL/UMAT Model Assembly:

Assemble the co-located 3-layer model:
  - Layer 1: Phase-Field UEL (Elements 1 - 14677, Type U1/U3)
  - Layer 2: Mechanical Displacement UEL (Elements 100001 - 114677, Type U2/U4)
  - Layer 3: Companion Visualization UMAT (Elements 200001 - 214677, Type CPE4/CPE3)
