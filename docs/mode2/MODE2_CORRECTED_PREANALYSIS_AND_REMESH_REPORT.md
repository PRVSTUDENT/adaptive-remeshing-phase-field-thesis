## 7. Physical Provenance of MISESERI & Williams Boundary Singularity

### 7.1 Layered UEL/UMAT Continuum Architecture
The phase-field implementation in Abaqus relies on three coincident element layers sharing physical nodal coordinates:
1. **Layer 1 (Phase-Field Diffusion, DOFs 3/3):** User elements `U1`/`U3` solving $l_0^2 \nabla^2 d - d + \frac{2 l_0}{G_c} (1-d) H = 0$.
2. **Layer 2 (Degraded Momentum Balance, DOFs 1, 2):** User elements `U2`/`U4` solving $\nabla \cdot \boldsymbol{\sigma} = \mathbf{0}$ with degraded constitutive relation $\boldsymbol{\sigma} = \left[(1-d)^2 + k\right] \boldsymbol{\sigma}_0^+ + \boldsymbol{\sigma}_0^-$.
3. **Layer 3 (Companion Visualization & Indicator Layer, DOFs 1, 2):** Standard Abaqus continuum elements (`CPE4`/`CPE3`, Elset `All_elem` / `umatelem`) sharing displacement DOFs $(u_x, u_y)$ with Layer 2, assigned `*User Material, name=UMAT_MAT` with $E_{\text{UMAT}} = 10^{-11}\,\text{kN/mm}^2 = 10^{-8}\,\text{MPa}, \nu = 0.3$.

### 7.2 UMAT Subroutine Audit & Scale Invariance
Direct code inspection of `SUBROUTINE UMAT` in `f42_mixed_uel_mode2_miehe.for` proves:
- `DDSDDE` is constructed purely as isotropic linear-elastic stiffness from $E_{\text{UMAT}}$ and $\nu$.
- Companion stress `STRESS` is computed as $\boldsymbol{\sigma}_{\text{passive}} = \mathbf{C}_{\text{passive}} : \boldsymbol{\epsilon}$ without damage degradation $(1-d)^2$.
- Phase field $d$, history $H$, and strain energy $\psi_e$ are passed via common block `CB_STATE_TRANS` into `STATEV(14..16)` purely for visualization, without modifying `STRESS`.
- Abaqus evaluates `MISESERI` via Zienkiewicz-Zhu (1987, 1992) superconvergent patch recovery on Layer 3:
  $$\text{MISESERI}_e = \left( \int_{\Omega_e} (\sigma^*_{\text{vm}} - \sigma_{\text{vm}})^2 \, d\Omega \right)^{1/2}$$
- Because $\boldsymbol{\sigma}_{\text{passive}} = \frac{E_{\text{UMAT}}}{E_{\text{phys}}} \boldsymbol{\sigma}_{\text{phys}}$, both $\text{MISESERI}$ and $\text{MISESAVG}$ scale linearly with $E_{\text{UMAT}}$.
- In the normalized relative error ratio:
  $$\eta_e = \frac{\text{MISESERI}_e}{\text{MISESAVG}} \equiv \frac{\widetilde{\text{MISESERI}}_e}{\widetilde{\text{MISESAVG}}}$$
  the scaling constant $E_{\text{UMAT}}$ cancels identically. Thus, the relative spatial error field $\eta_e(x, y)$ is mathematically exact and scale-invariant.

### 7.3 Boundary Condition Verification & Williams Corner Singularity
- Pandey & Kumar (2025) Section 4.2 & Fig. 4(b) prescribe a clamped bottom ($u_x = u_y = 0$), horizontal shear on top ($u_y = 0, u_x = \bar{u}$), and traction-free lateral sides ($x=0, x=1$).
- Our input decks (`Job-1_UEL_paper_horizon.inp` and `M2_CORRECTED_JOB2_ET3PCT_STABILIZED.inp`) strictly implement these exact BCs.
- At the bottom-right corner $(1.0, 0.0)$, the clamped bottom meets the traction-free vertical flank. In linear elasticity, this $90^\circ$ wedge exhibits a classic Williams singularity with leading eigenvalue $\lambda \approx 0.7583$ (for $\nu = 0.3$), yielding asymptotic stress $\sigma \sim r^{-0.242}$ and stress gradient $\nabla \sigma \sim r^{-1.242}$.
- Coarse linear finite elements cannot resolve this gradient, generating an elevated Zienkiewicz-Zhu recovery jump ($4.56\text{--}4.93\times$ higher than the crack tip).
- This proves that the bottom-right corner concentration is **a true physical boundary singularity**, not a numerical bug or companion artifact. Bounding the adaptive refinement via a physical corridor envelope ($W = 0.24\,\text{mm}$) is mathematically and physically justified to concentrate mesh resources on fracture.
