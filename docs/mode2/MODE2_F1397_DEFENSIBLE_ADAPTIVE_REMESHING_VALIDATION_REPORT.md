## 3. Priority B: Force Discrepancy Audit & Normalization Methodology

### 3.1 Pointwise Force Discrepancy Profile
A 4,000-point uniform displacement grid ($u_x \in [0.0, 20.0]\,\mu\text{m}$, $\Delta u = 0.005\,\mu\text{m}$) was interpolated between Fine 72k ($4{,}022$ increments) and Adaptive ET3 ($4{,}000$ increments).

- **Global Maximum Discrepancy:**
  - Displacement: $u_x = 10.2050\,\mu\text{m}$ (Step 2 Increment 41 in 72k, Step 2 Increment 41 in ET3)
  - Fine 72k Reaction Force: $F_{72k} = 402.0699\,\text{N}$
  - Adaptive ET3 Reaction Force: $F_{ET3} = 335.6220\,\text{N}$
  - Signed Difference: $\Delta F = -66.4479\,\text{N}$
  - Magnitude: $|\Delta F| = 66.4479\,\text{N}$
  - Percentage of Global Peak Force ($415.9895\,\text{N}$): $\mathbf{15.97\%}$

### 3.2 Underlying Physical and Numerical Mechanism
Inspection of the solver increments surrounding $u_x = 10.205\,\mu\text{m}$ reveals that this difference is a structural post-initiation phase shift, not a numerical divergence:
1. In Adaptive ET3, after peak initiation ($412.21\,\text{N}$ at $u_x = 9.41\,\mu\text{m}$), the crack initiates and drops steeply, reaching a local minimum of $335.37\,\text{N}$ at $u_x = 10.21\,\mu\text{m}$. The coarser peripheral mesh surrounding the refinement corridor allows faster localized elastic relaxation.
2. In Fine 72k, the uniform fine mesh ($h = 3.75\,\mu\text{m}$ everywhere) sustains an elevated secondary plateau with $RF_1 \approx 402.9\,\text{N}$ through $u_x \approx 10.17-10.20\,\mu\text{m}$ before softening sharply to $338\,\text{N}$ at $u_x \approx 10.7\,\mu\text{m}$.
3. Because both curves drop steeply but at slightly different displacements, the pointwise vertical difference peaks dramatically at $u_x = 10.205\,\mu\text{m}$ ($-66.45\,\text{N}$). By $u_x = 12.0\,\mu\text{m}$, the curves re-converge with errors dropping back to $\sim 15-20\,\text{N}$.

### 3.3 Normalization Discipline: Global Peak vs Sub-Range
In Task F1396, a post-peak propagation NRMSE of $38.62\%$ was reported. That value resulted from normalizing by the local post-peak range:
$$\Delta F_{\text{prop}} = F_{\max,\text{prop}} - F_{\min,\text{prop}} = 389.39\,\text{N} - 335.62\,\text{N} = 53.77\,\text{N}$$
Because the denominator was artificially compressed ($\Delta F = 53.77\,\text{N}$), an RMSE of $20.77\,\text{N}$ produced $20.77 / 53.77 = 38.62\%$.

When normalized rigorously against the physical problem scale ($F_{\max} = 415.9895\,\text{N}$):
- **Linear Elastic Regime ($0 - 6.0\,\mu\text{m}$, 1,201 points):** $\text{RMSE} = 0.677\,\text{N} \implies \mathbf{\text{NRMSE}_{F_{\max}} = 0.16\%}$
- **Entire Pre-Peak Regime ($0 - 9.47\,\mu\text{m}$, 1,895 points):** $\text{RMSE} = 3.096\,\text{N} \implies \mathbf{\text{NRMSE}_{F_{\max}} = 0.74\%}$
- **Near-Peak & Initiation Regime ($6.0 - 11.0\,\mu\text{m}$, 1,001 points):** $\text{RMSE} = 21.716\,\text{N} \implies \mathbf{\text{NRMSE}_{F_{\max}} = 5.22\%}$
- **Post-Peak Propagation Regime ($11.0 - 20.0\,\mu\text{m}$, 1,801 points):** $\text{RMSE} = 20.766\,\text{N} \implies \mathbf{\text{NRMSE}_{F_{\max}} = 4.99\%}$
- **Entire Post-Peak Regime ($9.47 - 20.0\,\mu\text{m}$, 2,107 points):** $\text{RMSE} = 24.184\,\text{N} \implies \mathbf{\text{NRMSE}_{F_{\max}} = 5.81\%}$
- **Global Full Horizon ($0.0 - 20.0\,\mu\text{m}$, 4,001 points):** $\text{RMSE} = 17.662\,\text{N} \implies \mathbf{\text{NRMSE}_{F_{\max}} = 4.25\%}$

Both normalizations are reported transparently in thesis figures and text, documenting that the apparent $38.62\%$ is an artifact of local sub-range scaling.
