\chapter{Stage F: Mode-II Mixed-Mode Phase-Field Fracture Benchmark}
\label{chap:stage_f_mode_ii}

\section{Problem Definition and Model Description}
The Mode-II pure-shear phase-field fracture benchmark evaluates the performance of the staggered user-element implementation under shear-dominated crack propagation. The specimen geometry consists of a square plate of length $L = 1.0\,\text{mm}$ and height $H = 1.0\,\text{mm}$ containing an initial horizontal notch of length $a_0 = 0.5\,\text{mm}$ at $y = 0.5\,\text{mm}$.

The material properties are specified as:
\begin{itemize}
    \item Young's modulus: $E = 210.0\,\text{GPa}$
    \item Poisson's ratio: $\nu = 0.30$
    \item Critical energy release rate: $g_c = 2.7 \times 10^{-3}\,\text{kN/mm} = 2700\,\text{J/m}^2$
    \item Phase-field length scale: $l_c = 0.015\,\text{mm}$
\end{itemize}

Boundary conditions enforce pure shear loading. The bottom edge ($y = 0\,\text{mm}$) is fixed in the vertical direction ($U_2 = 0$), while horizontal shear displacement $U_1 = \Delta u$ is applied to the top boundary ($y = 1.0\,\text{mm}$).

\section{Numerical Discretization and Solver Configuration}
The baseline $H_0$ mesh comprises $N_{\mathrm{elem}} = 3930$ quadrilateral physical elements and 4000 nodes. The refined reference $H_1$ mesh utilizes element size $h_1 = 0.0025\,\text{mm}$ ($h_1/l_c = 0.1667$) with $N_{\mathrm{elem}} = 12,064$ physical elements (36,192 layered UEL/UMAT elements) and 12,382 nodes. The formulation utilizes a staggered phase-field UEL/UMAT user-element formulation with overlay facsimile elements.

The corrected loading schedule applies a total displacement of $U_1 = 0.0100\,\text{mm}$ across two steps:
\begin{enumerate}
    \item Step 1: Pre-peak linear shear loading up to $U_1 = 0.0050\,\text{mm}$ (500 increments).
    \item Step 2: Shear fracture propagation up to $U_1 = 0.0100\,\text{mm}$ (2000 increments).
\end{enumerate}

\section{Execution and Computational Results}
\subsection{Baseline $H_0$ Solver Result}
The serial $H_0$ solver run (PBS Job ID \texttt{1379393.mmaster02}) was executed on the HPC cluster using Abaqus 2023 with 1 CPU and 16\,GB memory. It completed all 2000 increments with peak reaction force $F_{1,\max} = 0.3733\,\text{kN}$ and complete fracture ($\max(d) = 0.9909$).

\subsection{Reference $H_1$ Uniform Solver Result}
The $H_1$ uniform reference serial solver run (PBS Job ID \texttt{1379433.mmaster02}) was executed on HPC node \texttt{mnode104/0} using Abaqus 2023 with 1 CPU and 32\,GB memory.

Key numerical and scientific findings for $H_1$:
\begin{itemize}
    \item \textbf{Technical Completion:} Abaqus completed all 2,500 increments cleanly with solver return code 0. Total wall-clock time was 2,579 seconds ($\approx 43.0$ minutes), CPU time was 2,486 seconds ($\approx 41.4$ minutes), and peak memory usage was 1.01\,GB.
    \item \textbf{Reaction Force Response:} The reaction force $RF_1$ reached $0.1214\,\text{kN}$ at $U_1 = 0.0100\,\text{mm}$.
    \item \textbf{Phase-Field Damage Evolution:} The phase field $d = \text{SDV15}$ evolved to $\max(d) = 0.2747$, remaining in the initiation/pre-peak regime for the $U_1 = 0.0100\,\text{mm}$ endpoint.
    \item \textbf{Scientific Classification:} Classified as \texttt{stage\_f\_mode\_ii\_h1\_uniform\_serial\_validation\_fail} due to pre-peak damage state ($d < 0.50$).
\end{itemize}

\subsection{Reference $H_1$ Endpoint Sweep Batch Results and Reference Freeze}
To evaluate post-peak fracture evolution and complete force drop, a four-job loading endpoint sweep ($U_1 \in \{0.015, 0.020, 0.030, 0.040\}\,\text{mm}$) was executed for the $H_1$ uniform reference mesh ($N_{\mathrm{elem}} = 12,064$, $h_1 = 0.0025\,\text{mm}$) under task \texttt{F2-H1-ENDPOINT-SWEEP-BATCH} (PBS Job IDs \texttt{1379481.mmaster02}--\texttt{1379484.mmaster02}).

Key numerical and scientific findings from the endpoint sweep:
\begin{itemize}
    \item \textbf{Peak Response Invariance:} Across all four endpoint variants, initial shear stiffness was identical ($K_0 = 12.8266\,\text{kN/mm}$) and peak reaction force was $RF_{1,\max} = 0.139789\,\text{kN}$, occurring at $U_1 = 0.0120\,\text{mm}$.
    \item \textbf{Post-Peak Softening Trajectory:}
    \begin{itemize}
        \item $U_1 = 0.015\,\text{mm}$ (\texttt{1379481.mmaster02}): final $RF_1 = 0.1045\,\text{kN}$ (25.22\% force drop), walltime 1\,h 26\,m.
        \item $U_1 = 0.020\,\text{mm}$ (\texttt{1379482.mmaster02}): final $RF_1 = 0.0812\,\text{kN}$ (41.89\% force drop), walltime 2\,h 02\,m.
        \item $U_1 = 0.030\,\text{mm}$ (\texttt{1379483.mmaster02}): final $RF_1 = 0.0363\,\text{kN}$ (73.99\% force drop), walltime 3\,h 18\,m.
        \item $U_1 = 0.040\,\text{mm}$ (\texttt{1379484.mmaster02}): final $RF_1 = 0.0167\,\text{kN}$ (88.07\% force drop), walltime 4\,h 33\,m.
    \end{itemize}
    \item \textbf{Damage Saturation and Validation Policy:} All four jobs completed Abaqus solver execution and ODB data extraction cleanly with return code 0. Under the revised 3-tier validation policy ($d \le 1.0001$ normal pass, $1.0001 < d \le 1.01$ technical pass with warning \texttt{damage\_upper\_bound\_small\_overshoot}, $d > 1.01$ failure), the minor phase-field damage overshoot ($\max(d) = 1.00498$, an overshoot of 0.498\%) is classified as a numerical quality warning, yielding a technical execution **PASS** (\texttt{technical\_pass = true}, validator return code 0, outer PBS wrapper exit 12).
    \item \textbf{Working Reference Displacement Freeze:} The reference loading endpoint for all continuing uniform reference and adaptive remeshing studies is frozen as $U_{1,\mathrm{ref}} = 0.020\,\text{mm}$ (\texttt{u020}). This variant captures the invariant peak, a fully developed crack propagation zone, and a 41.89\% force drop at moderate computational cost.
\end{itemize}

\subsection{Stage F3 $H_2$ Uniform Reference and MISESERI Pre-Analysis Results}
Stage F3 established both the fine uniform reference baseline ($H_2$ mesh level) and the genuine ODB recovery-error indicator pre-analysis field ($\text{MISESERI}$) under tasks \texttt{F3-STAGE-F3-SUBMIT}, \texttt{F3-STAGE-F3-AUTH-PUBLISH-AND-ODB-VERIFY}, and \texttt{F3-STAGE-F3-COMBINED-SCIENTIFIC-CLOSEOUT}:
\begin{itemize}
    \item \textbf{Fine Uniform Reference $H_2$ Elastic Parity (\texttt{1379578.mmaster02}):} The $H_2$ uniform reference serial solver run ($N_{\mathrm{elem}} = 33,852$ physical UEL elements, $h_2 \approx 0.0025\,\text{mm}$ around notch tip) was executed on node \texttt{mnode104/0} using Abaqus 2023 with 1 CPU and 16\,GB memory, completing all 2,023 increments across 2 steps cleanly in 2\,h 04\,m walltime ($7,175.0\,\text{s}$ CPU time, $1.42\,\text{GB}$ memory). Under unified linear regression over the shared elastic window $0.0002\,\text{mm} \le U_1 \le 0.0020\,\text{mm}$ (19 points, $R^2 = 1.0000$), $H_2$ initial stiffness is $K_{\mathrm{H2}} = 12.7912\,\text{kN/mm}$, which matches $H_1$ ($K_{\mathrm{H1}} = 12.8093\,\text{kN/mm}$) to within $-0.1418\%$, establishing elastic parity. The preliminary $460.69\,\text{kN/mm}$ value was invalidated as an extraction sampling artifact.
    \item \textbf{H2 Nonlinear Fracture Status:} Because Job \texttt{1379578.mmaster02} stopped at the prescribed Step-2 displacement endpoint $U_1 = 0.0070\,\text{mm}$ ($RF_1 = 0.08747\,\text{kN}$, $d_{\max} = 0.119955$), execution remained strictly in the pre-peak elastic damage regime before the peak load ($U_1 = 0.0120\,\text{mm}$). Consequently, global post-peak softening for $H_2$ is classified as \texttt{fracture\_convergence\_unresolved}.
    \item \textbf{MISESERI Provenance Repair:} Official PBS Job \texttt{1379579.mmaster02} failed due to a node-parsing deck generator defect (classification: \texttt{technical-result-unusable-due-to-generator-defect}). A subsequent exploratory interactive run ($N_{\mathrm{elem}} = 3,930$ \texttt{CPE4} plane-strain elements, 15 coincident node pairs) yielded 3,930 finite element records with positive error indicator $\text{MISESERI} \in [0.0000687, 0.1870114]\,\text{GPa}$ at load $U_1 = 0.0010\,\text{mm}$ ($RF_1 = 0.04607\,\text{kN}$). Process violations M-099 and M-100 were recorded, and corrective evidence was relocated to \texttt{corrective\_interactive\_runs/2026-07-29T070232\_CEST/}.
\end{itemize}

\subsection{Stage F5 $H_2$ Compiler and Datacheck Qualification}
PBS job \texttt{1379939.mmaster02} qualified the frozen $H_2$,
$U_1=0.020\,\mathrm{mm}$ package in the selected cluster environment. Abaqus
2023 invoked ifort 2021.13.0, compiled and linked the exact UEL/UMAT source,
and completed datacheck with both PBS and Abaqus return codes equal to zero.
The job used one CPU on \texttt{mnode105/0}, required 19 seconds wall time and
957,660\,kB scheduler-reported memory, and passed all staged-file hash checks.
This result removes compiler availability as the immediate blocker, but it is
strictly a technical datacheck qualification: no full analysis was run and no
post-peak response, fracture convergence, remeshing accuracy, or parallel
safety claim follows from it.

\subsection{Stage F6 Full $H_2$ Post-Peak Result and Validation Boundary}
The frozen full $H_2$ package was executed as PBS job
\texttt{1379966.mmaster02} with one CPU and 16\,GB requested memory. Abaqus
2023 compiled and linked the UEL/UMAT source with ifort 2021.13.0 and
completed all 5,000 increments in 4\,h 43\,min wall time. The response reached
$U_1=0.020000\,\mathrm{mm}$, with peak
$RF_1=0.138727\,\mathrm{kN}$ at $U_1=0.011900\,\mathrm{mm}$ and final
$RF_1=0.080544\,\mathrm{kN}$, corresponding to a 41.94\% post-peak force
drop. The initial regression stiffness was
$12.79116\,\mathrm{kN/mm}$ ($R^2=0.99999949$).

Technical solver and extraction completion does not imply scientific
acceptance. The maximum extracted phase value was 1.004587, and the
framewise maximum-damage history contained 11 decreases, the largest being
$-1.0073\times10^{-4}$. The canonical Python 3.11 validation replay therefore
failed the declared irreversibility gate and classified the result as
\texttt{stage\_f\_mode\_ii\_h2\_uniform\_serial\_validation\_fail}. Energy
histories were unavailable from the retained output request. Consequently,
the run establishes endpoint attainment and the fine-mesh post-peak response,
but not accepted irreversibility, energy consistency, adaptive-remeshing
accuracy, parallel safety, or general convergence.

\subsection{Stage F7 Fixed-Material-Point Irreversibility Audit}
The read-only forensic ODB audit in PBS job
\texttt{1380084.mmaster02} tracked SDV15 at fixed material-point keys through
102 frames (101 adjacent-frame pairs). It found 1,120 strict negative
increments at 126 material points in 75 elements. The minimum local increment
was $-5.8532\times10^{-4}$, and 62 increments were below
$-10^{-4}$. Thus the decreases observed in the framewise maximum history
cannot be explained solely by a changing location of the maximum: the stored
phase field decreases at fixed material points. The $H_2$ run remains a
scientific irreversibility failure and is not accepted as a converged
fracture reference. A downstream report generator failed on a string-valued
CSV step label, but this occurred after the fixed-point ODB evidence had been
written and does not change that conclusion.

\subsection{Stage F7 Native MISESERI Remeshing API Boundary}
PBS job \texttt{1380085.mmaster02} corrected the earlier CAE driver-argument
collision and reached \texttt{mdb.models[name].RemeshingRule} with exact
source ODB and deck hashes. Rule construction rejected the first
\texttt{variables} entry because Abaqus Python 2.7 supplied a Unicode string
where the native API expected a recognized variables-entry type. The job is
classified as \texttt{remeshing\_api\_incompatible}. It executed no solver
and no native remesh and produced no candidate deck; therefore no adaptive
accuracy or refined-analysis claim follows.

\subsection{Stage F8 Qualification Preflight Boundary}
Source inspection established that SDV15 is the integration-point
visualization of the nodal U1 phase degree of freedom, whereas SDV16 stores
the maximum elastic-energy history. The frozen formulation updates the
history monotonically but applies no obstacle, projection, penalty, or active
set to the nodal phase unknown. A consistent penalty candidate was therefore
prepared by adding matched residual and tangent terms for negative
incremental phase gaps; an output-only SDV clamp was explicitly rejected.

No Stage F8 batch result exists. Both the frozen and candidate sources
compiled and linked under Abaqus 2023, and both decks passed input
processing, but the common minimal patch terminated during datacheck with
signal 11 in initial-stress/constraint processing. The required shared
preflight consequently stopped the batch before any qsub. The candidate
remains unqualified, and the exact \texttt{RemeshingRule.variables} type
remains unresolved.
