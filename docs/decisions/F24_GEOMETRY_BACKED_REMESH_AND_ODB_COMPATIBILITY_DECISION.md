## 1. Executive Summary

Official Abaqus software documentation establishes eleven strict rules for native adaptive remeshing:
1. Adaptive remeshing cannot operate on an orphan-mesh-only model.
2. The remeshed model must contain native geometry and an initial mesh.
3. The geometry-backed part created by `Part2DGeomFrom2DMesh` must be instantiated in `rootAssembly`.
4. The orphan-mesh instance must not remain the active remeshing target.
5. The remeshing rule must address actual geometry faces or cells.
6. For deterministic behavior, use an explicit `Region` built from geometry-backed instance faces rather than `region=MODEL`.
7. The geometry-backed instance should preserve the original instance name when possible so ODB instance correspondence is preserved.
8. `rootAssembly.regenerate()` must occur after the geometry-backed instance and region are created.
9. A separate `AdaptivityProcess` must not be added for the single manual `Model.adaptiveRemesh(odb)` route.
10. Use exactly one remesh route: `Model.adaptiveRemesh(odb)`.
11. No fallback remeshing API is permitted.

## 2. Workstream A — Geometry-Backed Model Construction Order

The exact corrected model-construction sequence is designed as follows:
1. Import source input deck (`source_deck.inp`) into `mdb.ModelFromInputFile`.
2. Identify orphan source part (`Part-1`) and instance (`Part-1-1`).
3. Record source model entities (materials `Elastic_Matrix`, section `Section-1`, element type `CPE4`, sets `bottom`, `top`, `notch_lower_face`, `notch_upper_face`, `notch_tip`, boundary conditions, equations).
4. Create geometry-backed part with `geom_part = m.Part2DGeomFrom2DMesh(name='Part-1-GEOM', part=orphan_part)`.
5. Assign section and material data to geometry-backed face geometry (`geom_part.SectionAssignment`).
6. Apply supported 2D mesh controls (`CPE4`, `STRUCTURED`).
7. Seed and generate initial mesh on geometry-backed part (`geom_part.seedPart(size=0.015)`, `geom_part.generateMesh()`).
8. Instantiate geometry-backed part as dependent assembly instance (`Part-1-1-GEOM`).
9. Preserve original instance name `Part-1-1` by renaming `orphan_instance` to `Part-1-1-ORPHAN` and `geom_instance` to `Part-1-1`.
10. Rebuild required part and assembly sets/surfaces.
11. Rebuild or rebind loads, boundary conditions, and equations to geometry-backed sets.
12. Suppress or remove the orphan-mesh assembly instance `Part-1-1-ORPHAN`.
13. Regenerate `rootAssembly` (`m.rootAssembly.regenerate()`).
14. Create an explicit `Region` from geometry-backed faces (`Region(faces=geom_instance.faces)`).
15. Create `MISESERI` `RemeshingRule` on that explicit face `Region`.
16. Perform pre-call recognition audit.
17. Permit `Model.adaptiveRemesh(odb)` only after audit pass.
